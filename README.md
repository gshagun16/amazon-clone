# 🛒 Amazon Clone

A responsive Amazon homepage clone built using **HTML5** and **CSS3**. This project recreates the layout and design of Amazon's home page to practice front-end development skills.

## 🚀 Features

- Responsive navigation bar
- Search bar with icon
- Hero banner section
- Product cards
- Hover effects on cards and buttons
- Responsive layout using Flexbox
- Media Queries for mobile devices
- Amazon-style footer

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries
- Font Awesome Icons
